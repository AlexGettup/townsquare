# Blood on the Clocktower Grimoire & Town Square

![social](https://user-images.githubusercontent.com/325521/102897760-d1147b00-4468-11eb-9d7b-63a204bc9fc1.png)

An unofficial online tool to play Blood on the Clocktower: the Storyteller's grimoire and a
shared town square, with live voting, character distribution and much more.

**[Play it online](https://alexgettup.github.io/townsquare/)**

## Where it comes from

This app is a fork. The original Townsquare was created by
**[Bra1n (Steffen Baumgart)](https://github.com/bra1n/townsquare)**, and **[nicholas-eden and
contributors](https://github.com/nicholas-eden/townsquare)** kept it up to date with new
characters, Loric, alternate alignments, custom jinxes and night orders. Everything listed under
[Original features](#original-features) is their work, and live game sessions still run on the original project's server.

This version, by [Alex (AlexGettup)](https://github.com/AlexGettup), aims to play a whole game
**without Discord**, as comfortably on a phone or tablet as on a computer. The changes of each
version are in [CHANGELOG.md](CHANGELOG.md) (also in the app's menu, under "What's New"), and
the plans in [ROADMAP.md](ROADMAP.md).

## What this version adds

### Talk without Discord

- **Voice chat** built in: players are isolated at night and woken by the Storyteller; during
  the day there's the town square, private conversations and open rooms
- **Text chat** with the same rules, plus a private channel with the Storyteller
- Noise suppression, volume per person, and connections that recover by themselves

### For the Storyteller

- **Guided night** through the night order, step by step
- **Info cards** like the official app, which players answer with one tap
- **Announcements**, a **day timer** and a day and night counter
- **Votes** for special characters (secret, pointing, vote values) and automatic ghost votes
- **Practice game** with made-up players to rehearse alone

### For players

- A clear **voting panel**, a **game diary** and private **notes** on each player
- Alerts when you are woken up or get information

### Phones, tablets and Spanish

- Designed for touch screens, installable on the home screen
- **Spanish** interface and game texts, from the official translations

## Original features

- Public Town Square and Storyteller Grimoire (toggle with **shortcut \[G\]**)
- Supports custom script JSON generated by the [Script Tool](https://script.bloodontheclocktower.com/)
- Live Session for Storyteller / Players including live voting and character distribution
- Includes all 3 base editions, Travellers, Fabled and Loric plus all experimental characters
- Night sheet and reminder text for each character ability to help storytellers
- Full homebrew support for hosting and playing games with your own sets of characters
- Many other customization options

[JayBotC](https://www.youtube.com/channel/UCNZy-4Rp877XtTHaIZdWYFQ) made two tutorial videos
for the original app. This version looks different in places, but the basics are the same:
[how to host a game](https://www.youtube.com/watch?v=lVRJPBXfqxg) and
[how to play a game](https://www.youtube.com/watch?v=VCpFnJFiCbk).

### Custom Script Support

Any custom script generated by the official [Script Tool](https://script.bloodontheclocktower.com/) is supported out of
the box and you only need to upload it to get the selected set of characters into your grimoire. If you want to customize
your script further, there is an additional `"_meta"` object that you can add/edit in the script JSON, with the following optional properties:

```json
[
  {
    "id": "_meta",
    "name": "Custom Script Name",
    "author": "Author's Name",
    "logo": "https://example.com/logo.png",
    "hideTitle": false,
    "background": "https://example.com/background.png",
    "bootlegger": ["Bootlegger rule 1", "Bootlegger rule 2", "etc"],
    "firstNight": [
      "dusk",
      "minioninfo",
      "demoninfo",
      "poisoner",
      "...",
      "dawn"
    ],
    "otherNight": ["dusk", "poisoner", "...", "dawn"]
  }
]
```

This will provide your local Grimoire (and those of your live session players) with more information to show about
your custom script - instead of "Custom Script" it would show "Deadly Penance Day" on the character reference sheet,
for example. The logo will be shown to your players after they have enabled custom images in the Grimoire menu.

### Custom Character Support

In order to add custom characters to your local Grimoire, you need to create a JSON definition for them,
similar to what is provided in the [`roles.json`](https://github.com/AlexGettup/townsquare/blob/main/src/roles.json) for the 3 base editions. Here's an example of how such a character
definition file might be written:

```json
[
  {
    "id": "acrobat",
    "image": "https://github.com/bra1n/townsquare/blob/main/src/assets/icons/acrobat.png?raw=true",
    "edition": "custom",
    "firstNight": 0,
    "firstNightReminder": "",
    "otherNight": 18,
    "otherNightReminder": "The Acrobat points to a player. If that player is or becomes drunk or poisoned tonight, the Acrobat dies.",
    "reminders": ["Chosen", "Dead"],
    "remindersGlobal": [],
    "setup": false,
    "name": "Acrobat",
    "team": "townsfolk",
    "ability": "Each night*, choose a player: if they are or become drunk or poisoned tonight, you die."
  },
  "investigator",
  "imp"
]
```

This definition JSON includes a custom character, the Acrobat, and 2 base game characters, the Investigator and the Imp.
For base game characters, it is sufficient to provide only the ID as a string, similar to what you get from the Script Tool.

**Required properties:** `id`, `name`, `team`, `ability`

- **id**: the internal ID for this character, without spaces or special characters<br>
  _Note_: this ID needs to be unique and can't be the same as any ID already used by an existing character, otherwise the custom character will be overwritten with the existing role!
- **image**: a URL to a PNG of the character token icon (should have a transparent background!)<br>
  _Note_: custom images will only be visible after enabling them in the Grimoire menu!
- **edition**: the ID of the edition for this character. can be left blank or "custom"
- **firstNight** / **otherNight**: the position that this character acts on the first / other nights, compared to all
  other characters<br>
  _Note_: must be a positive number or zero, with zero being treated as "does not act during the night"
- **firstNightReminder** / **otherNightReminder**: reminder text for first / other nights
- **reminders**: reminder tokens, should be an empty array `[]` if none
- **remindersGlobal**: global reminder tokens that will always be available, no matter if the character is assigned to a player or not
- **setup**: whether this token affects setup (orange leaf), like the Drunk or Baron
- **name**: the displayed name of this character
- **team**: the team of the character, has to be one of `townsfolk`, `outsider`, `minion`, `demon`, `traveller`, `fabled` or `loric`<br>
  _Note_: if you create a custom Fabled or Loric character, it will be automatically added to the game when the custom script is loaded
- **ability**: the displayed ability text of the character

For further details on the JSON structure, see the official app's [JSON Schema](https://github.com/ThePandemoniumInstitute/botc-release/blob/main/script-schema.json)
